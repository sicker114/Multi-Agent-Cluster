## 用例 1：数据库统计 + 计算 + 校验（覆盖 SQL / 统计 / Judge）
**业务需求**
> 统计近三个月各部门销售总额与环比增长，标注是否存在销量暴跌风险。

**请求**
```bash
curl -X POST http://localhost:8080/api/analysis/ask \
  -H "Authorization: Bearer <TOKEN>" -H "Content-Type: application/json" \
  -d '{"question":"统计近三个月各部门销售总额与环比增长，标注是否存在销量暴跌风险"}'
```

**预期链路**：Manager 识别 `[DATABASE, COMPUTE, COMPLIANCE]` → SQL Agent 走 `MONTHLY_TREND`/`SALES_BY_PERIOD` 取数 → 统计 Agent 计算 `total_amount / mom_growth`，环比 ≤ -30% 打「销量环比暴跌」风险 → Judge 交叉校验总额一致性 → 达标输出报告。

**预期输出（结构）**
```json
{
  "code": 200,
  "data": {
    "success": true,
    "report": "# 企业经营数据分析报告 ... ## 一、分析结论 ... ## 二、风险标注 - 销量环比暴跌 ...",
    "confidenceScore": 60~95,
    "riskTags": ["业务风险"] 或 [],
    "dataSources": [{"type":"database", ...}, {"type":"computation", ...}],
    "retryCount": 0,
    "tokenCost": ">0",
    "cacheHit": false
  }
}
```

## 用例 2：文档 + 数据库联合分析（覆盖 GraphRAG / SQL / 统计 / Judge）
**业务需求**
> 结合《销售管理制度》文档，分析当前库存赤字商品是否违反安全库存规定。

**前置**：上传一份含"安全库存"条款的 PDF/Word 文档。
```bash
curl -X POST http://localhost:8080/api/file/upload \
  -H "Authorization: Bearer <TOKEN>" \
  -F "file=@./销售管理制度.pdf" -F "category=经营制度"
# 可选：python -m scripts.init_graphrag   （批量建图谱）
```

**请求**
```bash
curl -X POST http://localhost:8080/api/analysis/ask \
  -H "Authorization: Bearer <TOKEN>" -H "Content-Type: application/json" \
  -d '{"question":"结合销售管理制度文档，分析当前库存赤字商品是否违反安全库存规定"}'
```

**预期链路**：Manager 识别 `[DOCUMENT, DATABASE, COMPUTE, COMPLIANCE]` → GraphRAG 检索安全库存条款证据 → SQL Agent 走 `INVENTORY` 取库存 → 统计 Agent 识别 `deficit_items`/`warn_items` → Judge 校验文档忠实度 + 数据一致性。

**预期输出**：报告「三、数据来源溯源」同时包含 `document` 与 `database`/`computation` 来源；若有赤字商品，`riskTags` 含「业务风险」，结论引用文档条款。

## 用例 3：低置信度触发反思重试（覆盖反思闭环 / Checkpoint）
**业务需求**
> 分析某个知识库中不存在的冷门指标（构造检索无强证据场景），验证反思重试。

**请求**
```bash
curl -X POST http://localhost:8080/api/analysis/ask \
  -H "Authorization: Bearer <TOKEN>" -H "Content-Type: application/json" \
  -d '{"question":"分析上个季度海外仓周转率与本地政策文档的合规差异"}'
```

**预期链路**：证据不足 → Judge 置信度 < 60 且 `retry_count < max_retry` → `need_retry=true` → 条件边路由回 `sql_agent` 二次检索 → 达到 `max_retry`(默认 2) 仍不达标 → 返回带「低置信度」风险提示的最佳结果。

**预期输出**
```json
{
  "data": {
    "success": false,
    "confidenceScore": "<60",
    "riskTags": ["低置信度", "文档缺失"] 之一或组合,
    "retryCount": 1~2,
    "errorCode": "LOW_CONFIDENCE",
    "errorMessage": "置信度未达阈值，返回带风险提示的最佳结果"
  }
}
```
> 验证点：`retryCount > 0` 证明反思重试闭环生效；`session_id` 相同再次调用可命中 Checkpoint 恢复。
