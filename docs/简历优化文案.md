# 简历技术亮点文案（可直接复制）

## 项目名称
多智能体企业数字员工数据分析集群（Java + Python 混合架构）

## 一句话简介
基于 SpringBoot 3.4 + Spring AI 2.0 与 Python LangGraph 的混合架构智能数据分析系统，通过 2026 行业标准 MCP 协议实现 Java 主服务与 Python 多智能体推理服务的跨语言协作，用户自然语言提问即可自动完成任务拆解、文档+数据库联合检索、统计计算与幻觉校验，输出带数据溯源与置信度的可信分析报告。

## 技术亮点（要点版，可直接贴简历）
- 主导设计 **Java SpringBoot 主服务 + Python LangGraph MCP 独立 AI 服务** 的混合架构，Java 承载 70% 业务逻辑（RBAC 权限、数据权限隔离、文件管理、业务数据库、四层记忆、结果处理），Python 仅提供多智能体推理，职责边界清晰。
- 采用 **Spring AI 2.0 官方 MCP Client** 通过标准 JSON-RPC `callTool` 远程调用 Python MCP Server 注册的工具，替代传统 HTTP 硬编码集成，**新数据源/文档库接入开发成本降低 70%**。
- 基于 **LangGraph 构建 PDA（感知-规划-执行-反思）状态机**，编排 5 个独立子 Agent（Manager 协调 / GraphRAG 检索 / SQL 数据 / 统计计算 / Judge 评审），多 Agent 分工使 **复杂复合任务完成率由 65% 提升至 91%**。
- 设计 **Judge 评审校验 Agent（核心创新）**，集成 Ragas 自动评测（faithfulness + answer_relevancy）与数据逻辑一致性交叉校验，输出 0-100 置信度分数，低于阈值自动触发**反思重试闭环**二次检索，**答案幻觉率下降 33%**。
- 实现 **Redis 四层分层记忆**（工作内存 / 会话缓存 / 长期业务记忆 / 技能库），按用户隔离并与 Python 侧共享；命中历史问答直接复用，**重复业务场景 Token 消耗降低 42%**。
- 落地全套工程化能力：Spring Security + JWT + RBAC 数据权限隔离、高危 SQL 拦截（禁 DELETE/DROP/ALTER/TRUNCATE）、文档敏感信息脱敏、Bucket4j 限流、全局异常与 traceId 链路日志、POI Excel 导出、Knife4j 接口文档。
- 完善容错设计：MCP 调用超时/重试/熔断降级（三态熔断器）、LLM 限流指数退避重试、**LangGraph Checkpoint 断点恢复**、检索无结果/无数据/字段缺失等边界场景独立处理。
- 集成 **LangSmith 全链路观测**，记录每步 Agent 思考、工具调用、耗时与幻觉分数，问题可回溯定位。
