# 本地启动指引（非 Docker）

> 适用场景：本机**未安装 Docker**（当前环境），采用本地进程方式启动。
> 已配置好的：JDK 17（`JAVA_HOME=D:\Java\jdk-17`）、Python 3.11、Java jar 已打包。

## 步骤 1：启动 MySQL 并初始化库表（需你操作）

本机已装 `D:\Java\mysql-8.0.34-winx64`。启动 mysqld 后执行：

```powershell
# 用 root 登录后建库（若 schema.sql 里已含 CREATE DATABASE 可跳过建库）
& "D:\Java\mysql-8.0.34-winx64\bin\mysql.exe" -uroot -p -e "CREATE DATABASE IF NOT EXISTS enterprise_agent DEFAULT CHARACTER SET utf8mb4;"
# 导入建表 + 初始化数据（admin/zhangsan/lisi 密码均为 123456）
& "D:\Java\mysql-8.0.34-winx64\bin\mysql.exe" -uroot -p enterprise_agent < "d:\DevProjects\new_project_260810\java-service\src\main\resources\schema.sql"
```

> 若 root 密码不是 `root123456`，启动 Java 前设置 `$env:MYSQL_PASSWORD='你的密码'`。

## 步骤 2：启动 Redis（需你操作）

本机若已装 Redis 直接启动 `redis-server`；未装可下载 Windows 版或用 WSL。确认 `redis-cli ping` 返回 `PONG`。

## 步骤 3：设置 LLM 密钥（强烈建议）

```powershell
$env:LLM_API_KEY  = 'sk-你的真实DeepSeek密钥'
$env:LLM_BASE_URL = 'https://api.deepseek.com'
$env:LLM_MODEL    = 'deepseek-chat'
```
不设则走离线降级：Chroma 内置 embedding + Judge 启发式评分，链路能通但无真实 LLM 报告。

## 步骤 4：启动 Python MCP 服务

```powershell
.\deploy\start-python-local.ps1
```
首次会自动建 `.venv` 并安装依赖（较重，耐心等）。看到 SSE 监听 `:8000` 即成功。

## 步骤 5：启动 Java 主服务（另开一个终端）

```powershell
.\deploy\start-java-local.ps1
```
启动后访问 `http://localhost:8080/doc.html`（Knife4j 接口文档）验证。

## 步骤 6：初始化 GraphRAG 知识库（可选，检索 Agent 需要）

先通过 Java 接口上传若干 PDF/Word/TXT 文档，再执行：

```powershell
# 复用 Python venv
& d:\DevProjects\new_project_260810\python-mcp-service\.venv\Scripts\python.exe -m scripts.init_graphrag
# 或从本地目录直接建索引
& ...\python.exe -m scripts.init_graphrag --local-dir .\docs
```

## 若之后要用 Docker（更省心）
安装 Docker Desktop 后，在**项目根目录**执行：
```powershell
docker compose -f deploy/docker-compose.yml up -d --build
```
compose 路径已修正为相对 `deploy/` 的 `../`，schema.sql 首启动自动导入，无需手动建库。
